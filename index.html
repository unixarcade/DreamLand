A compact compiler and stack VM. Expressions compile once; programs execute bytecode rather than reparsing source in the hot loop.

DESCENT

Metal / COFF / UEFI

Raw bytes, machine images, x86-64 COFF objects, firmware boot. The environment can live before a conventional operating system exists.
